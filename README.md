# 사막의 황금 (Desert Gold · 1880)

1880년 서부 사막에서 전설의 금광을 찾는 **도트 그래픽 생존 어드벤처**입니다.
컴퓨터와 모바일(안드로이드·아이폰) 브라우저에서 바로 실행되며, 설치가 필요 없습니다.

## 목표
늙은 광부 하스켈이 남긴 **잃어버린 광산**을 찾아 시금소에 소유권을 등록하고, 은행에 **$10,000**를 모으세요.

## 실행
- GitHub Pages 등 웹 서버에 올리면 바로 실행됩니다.
- 로컬: `python3 -m http.server` 후 `http://localhost:8000` 접속
- 모바일에서는 "홈 화면에 추가"로 앱처럼 설치할 수 있고, 오프라인에서도 실행됩니다 (PWA).
- **가로 화면 전용**입니다. 휴대폰을 세로로 들면 가로로 돌리라는 안내가 나오고 게임이 멈춥니다.

## 조작
| | 컴퓨터 | 모바일 |
|---|---|---|
| 이동 | 방향키 / WASD | 왼쪽 조이스틱 |
| 행동·확인 | 스페이스 / 엔터 / Z | 행동 버튼 · 화면 탭 |
| 가방·뒤로 | ESC / X / I | 가방 버튼 |
| 사격 | F / C | 사격 버튼 |
| 지도 | M | 가방 → 지도 보기 |
| 저장 | 가방 → 게임 저장하기 / 저장하고 나가기 | 같음 |

## 주요 내용
- **실시간 시간·날씨**: 실제 1초 = 게임 3분. 낮 기온이 화씨 110도까지 오르고, 더울수록 물이 빨리 줄어듭니다. 건물은 대부분 08~18시에 영업합니다.
- **생존**: 체력(녹색·노란색·빨간색), 식량, 물. 방울뱀 독, 갈증, 굶주림, 갱도 붕괴, 강도로 죽을 수 있습니다.
- **마을**: 잡화점, 살롱(포커·소문), 시금소, 은행, 병원, 호텔(저장), 마굿간, 신문사, 보안관 사무소, 우물
- **돈 벌기**: 5장 드로우 포커, 강가 사금 채취, 버려진 광산 채굴, 낚시, 강도 현상금
- **뼈 지도 조각 6개**: 포커(2), 버려진 광산 깊은 곳(2), 늙은 탐광자(1), 검은 모자 갱단 두목(1). 조각이 늘어날수록 지도의 붉은 원이 좁아집니다.
- **무작위 세계**: 새 게임마다 지형, 강, 광산, 전설의 광산 위치가 달라집니다.

## 구성
- 순수 HTML5 Canvas + JavaScript (라이브러리 없음), 384×216 해상도를 화면에 맞게 확대
- 모든 그래픽은 코드로 그린 도트 그래픽이고, 효과음과 음악은 WebAudio로 만든 칩튠입니다
- 한글 글꼴: [Galmuri](https://github.com/quiple/galmuri) (SIL OFL 1.1, `fonts/Galmuri-LICENSE.txt`)
- 앱 아이콘 다시 만들기: `node tools/make-icons.js`
